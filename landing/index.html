Features

Built native. Built private.

Native OS input taps, a local SQLite database, and nothing else in the loop.

Native background capture

Keystrokes, clicks, scrolls, cursor distance and shortcut chords through WM_INPUT, CGEventTap and XInput2 — with negligible CPU overhead.

  • Windows
  • macOS
  • Linux

Strict local privacy

Never logs typed characters, passwords, clipboard or window titles. Only aggregate key codes and counts, in local SQLite.

Tray & stealth mode

Live quietly in the tray or vanish entirely. Wake it any time with CtrlAltShiftT.

Rich analytics

Live WPM/CPM, mouse odometer, streaks, keyboard heatmap and treemap, 365-day calendar, hourly trends, per-app attribution.

Typing test, shortcuts & reports

Speed tests in English, فارسی and Code. A platform-aware shortcut atlas. Seven styled PNG report cards you can actually share.

  • English
  • فارسی
  • Code
  • PNG export

9 languages, 4 palettes

Full RTL Persian with a Jalali calendar. Light and dark themes, 80–150% UI scaling, CSV and JSON export.

Privacy

Your data never leaves
your machine.

No account. No analytics SDK. No network request carrying your activity. Everything lives in typecount.sqlite3 on your disk — export it, back it up, or merge databases across machines whenever you want.

Read the source on GitHub

✕ Never stored

  • Typed characters & passwords
  • Clipboard contents
  • Window titles & screen coordinates
  • Anything sent to a server

✓ Stored locally

  • Aggregate key codes & click counts
  • Scroll steps & cursor distance
  • Optional foreground app names
  • Daily totals in SQLite
